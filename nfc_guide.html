NFC Testing Guide

Complete guide for testing NFC-based profile opening on SocialNet

Requirements

Before testing NFC functionality, ensure you have:

  • Android Device: NFC-enabled Android smartphone or tablet
  • Chrome Browser: Version 89 or later (Web NFC only works in Chrome on Android)
  • HTTPS Connection: Web NFC requires a secure context (HTTPS or localhost)
  • NFC Tags: NTAG213, NTAG215, NTAG216, or similar writable NFC tags
  • NFC Tools App: For writing data to NFC tags (free on Play Store)
Important: Web NFC is NOT supported on iOS (iPhone/iPad) or any browser other than Chrome on Android. Safari, Firefox, and Edge do not support Web NFC.

Writing User ID to NFC Tag

Follow these steps to write a user ID to an NFC tag using the NFC Tools app:

1 Install NFC Tools

Download "NFC Tools" from Google Play Store (free version is sufficient).

2 Open the App

Launch NFC Tools and tap on the "Write" tab at the bottom.

3 Add a Text Record

  1. Tap "Add a record"
  2. Select "Text" from the list
  3. In the text field, enter ONLY the user ID number (e.g., 1, 42, 123)
  4. Tap "OK" to save
Finding User ID: The user ID is the number in the profile URL. For example, if the profile URL is user_profile.php?id=5, the user ID is 5.

4 Write to Tag

  1. Tap "Write" button
  2. Hold your phone over the NFC tag
  3. Wait for the "Write complete" confirmation
✓ Success! Your NFC tag now contains the user ID and is ready for scanning.

Testing NFC Scanning

1 Access the Scanner

Open Chrome on your Android device and navigate to:

https://your-domain.com/social/nfc_scan.php

2 Grant Permissions

When prompted, allow NFC access for the website.

3 Start Scanning

Tap the "Start Scanning" button.

4 Scan the Tag

Hold your phone near the NFC tag. The NFC antenna is usually at the back-center of the phone.

5 View Profile

Upon successful scan, you'll see a preview of the user and be automatically redirected to their profile.

Testing on Localhost (XAMPP)

To test NFC on localhost, you need to access your XAMPP server from your Android device:

1 Find Your Computer's IP

Open Command Prompt and run:

ipconfig

Look for "IPv4 Address" (e.g., 192.168.1.100)

2 Configure XAMPP

Ensure Apache is running and accessible on your network. You may need to allow it through Windows Firewall.

3 Access from Android

On your Android Chrome browser, navigate to:

http://192.168.1.100/social/nfc_scan.php

(Replace with your actual IP address)

HTTP Limitation: Web NFC requires HTTPS in production. For local testing with HTTP, Chrome may still work if accessing via the device's local network, but this isn't guaranteed.

Troubleshooting

❌ "NFC Not Supported" Error

  • Ensure you're using Chrome on Android (not Samsung Internet, Firefox, etc.)
  • Check if your device has NFC hardware
  • Verify Chrome is updated to version 89 or later

❌ "Permission Denied" Error

  • Go to Chrome Settings → Site Settings → NFC
  • Allow NFC for the website
  • Clear site data and try again

❌ "NFC is Disabled" Error

  • Enable NFC in your device settings (Settings → Connections → NFC)
  • Restart your device if NFC was just enabled

❌ Tag Not Reading

  • Move the tag closer to the NFC antenna (usually center-back of phone)
  • Hold the tag steady for 1-2 seconds
  • Remove phone case if it's thick
  • Ensure the tag isn't damaged

❌ "No Valid User ID Found"

  • Verify the tag contains only a number (the user ID)
  • Re-write the tag using NFC Tools
  • Try using a different NFC tag

❌ "User Not Found"

  • Confirm the user ID exists in your database
  • Check the API endpoint is accessible: /social/api/nfc.php?id=1

Recommended NFC Tags

For storing user IDs, any standard NFC tag works. Recommended types:

Tag Type Memory Use Case
NTAG213 144 bytes Perfect for user IDs (plenty of space)
NTAG215 504 bytes Good for IDs with additional data
NTAG216 888 bytes For storing URLs or larger data
Mifare Classic 1K 1024 bytes Widely available, good compatibility

Where to buy: Amazon, AliExpress, or local electronics stores. NFC stickers and cards are both suitable.

GET /social/api/nfc.php?id={user_id}
